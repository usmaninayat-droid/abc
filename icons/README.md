# Tajmee'e / Tadweer — prototype icons

SVG icons used in the My Complaints prototype.

- **24×24** viewBox, **2px** stroke, round caps/joins.
- Line icons use `stroke="currentColor"`; solid icons (`dead-animals-collection`, `ui/severity-flag`) use `fill="currentColor"`.
- Recolor by setting CSS `color` on the element (or the parent), e.g. `<span style="color:#22c882">…</span>`, or swap `currentColor` for a fixed hex.

## Folders
- `services/` — the 26 service-type icons (filename = service slug).
- `ui/` — rail, card-meta and sheet-control icons.

Open `preview.html` to see them all.
